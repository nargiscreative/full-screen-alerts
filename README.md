# Haunted Parlour — Full Screen Alerts (media)

Hosted animation files for the Haunted Parlour full-screen alert widget.

The videos are published as **release assets**, not in the git tree — they are
each over GitHub's 100 MiB file limit, and release assets allow up to 2 GB.

See the [latest release](../../releases/latest) for download links.

Transparent VP9 WebM, 15 seconds, no audio.
